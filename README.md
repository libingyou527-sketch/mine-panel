# mine panel

> 默认离线、开源、仅记录使用者**本人**的本地行为日志与游戏化个人画像面板；聊天页可选接入外部大模型。

- 体积 520,335,012 字节（约 496.23 MiB），架构 `arm64-v8a` / `x86_64`，minSdk 26（Android 8.0 及以上）；包内已内置基线模型权重。

## 用途与适用边界（强制阅读）

- 本应用**仅用于记录设备持有者本人**的使用元数据，面向个人专用设备。
- **共享设备下，元数据无法天然区分使用者**：如果设备多人共用，应用记录的是设备层面的使用痕迹，不能归因到具体某个人，请勿用于判断或追踪他人。
- 本应用**不监控他人、不做隐蔽监控**；不读取聊天/通知正文/屏幕内容/联系人；默认离线、不上传、不含账号体系、不含广告 SDK、不做云备份。仅聊天页在你显式启用外部模型时向自填的第三方服务发送对话，见下方「网络与外部模型」。
- 面板属性与文案仅为自我观察的参考，**不构成健康、心理或人格诊断**。

## 网络与外部模型

- 默认离线：应用清单虽声明 `INTERNET`（供可选外部模型通道），但**不含**遥测、崩溃上报、远程配置、账号登录、广告 SDK 与云备份，也不申请 `ACCESS_NETWORK_STATE` 读取网络状态。
- 本地模型推理在设备内完成，断网可完整使用；失败时降级为规则模板文案。
- 聊天页「设置」可启用外部大模型：走 OpenAI 兼容协议，自填接口地址（Base URL）、模型名与 API Key，预置 DeepSeek / 通义千问 / Kimi / 智谱 GLM / OpenRouter / OpenAI 模板，也可自定义。API Key 经 Keystore AES-GCM 加密后存本地密文，明文不落地。
- 仅在外部模型已启用且接口地址、模型名、Key 三项齐全时，对话的系统提示与历史才会发送到你填写的端点；关闭、配置不完整、网络不可用或调用失败时，自动降级为本地内置模型，再不可用落模板兜底。面板回顾等其他推理通道始终只走本地模型。
- 构建期从 Maven 拉取依赖属于常规开源构建流程，不代表应用运行时具备联网能力；运行时未引入第三方网络库（远程请求用 JDK `HttpURLConnection`），依赖审计见 [`sbom/dependencies.md`](sbom/dependencies.md)。

## 数据流概览

```
采集（使用情况元数据 / 可选插件）
  → 本地加密存储（Room + SQLCipher，Keystore 包裹密钥）
  → 日聚合 + 周滑动窗口（WorkManager）
  → 规则引擎：六维属性 0–100、置信度、依据摘要（数值只在这里产生）
  → 本地模型：输入聚合后的 JSON 片段，输出草案文案（不产出数值、不输出人格结论）
  → 待确认队列：「自动确认记忆」默认开启，仅本地模型成功产出、通过校验且非重复的草案自动裁决；其中仅记忆要点沉淀为正式记忆，状态标签与回顾文案只在草案表保留已确认身份；可在队列页关闭，关闭后由用户确认/修正/丢弃后才写入正式记忆；模板降级、超时或异常内容仍回落队列人工确认
  → 手写片段：本人在队列页「记一笔」直接录入（可选心情、粗类别、时间锚点），不经草案队列即入正式记忆
  → 长周期回顾：按自然月/季/年汇编本窗使用概览、六维分值与记忆/片段要点，模型优先、模板兜底生成回望草稿，仍进确认队列；回顾页附跨窗节律趋势对比（屏幕时长/记忆/片段环比）
  → 记忆本专区：主面板「记忆本」入口，只读分区浏览已确认记忆、状态标签、回顾文案、主动片段与里程碑
  → 游戏化面板：雷达图、经验条、徽章、时间轴、属性依据页；若本次为模板降级，主界面弹窗提示一次，关闭后不再重复弹出
  → 本地聊天：主界面「聊天」入口，支持多个独立会话，可新建/切换/重命名/删除，列表按最近消息排序；每条消息归属某一会话，可长按删除单条；回复默认由本地模型自由文本生成，也可在聊天页「设置」中启用外部大模型（OpenAI 兼容，失败自动降级本地），模型不可用时落中性兜底，不回写数值。上下文按 token 估算预留输出/系统/记忆/安全余量，在完整轮次边界截断并限制最近轮次；可「整理记忆」让模型从对话提炼候选要点，经本人采纳后作为背景注入后续对话，未采纳不落库；长期要点全局共享，不归属单一会话。聊天可独立导出为当前会话 JSON（对话消息 + 全局已采纳要点，不含候选与使用分值），也可从本地 JSON 导入恢复：消息新建会话承载、要点去重并入全局记忆；「清空当前」只删当前会话消息，保留全局要点
```

## 权限清单

### 默认申请

| 权限 | 用途 |
|---|---|
| `PACKAGE_USAGE_STATS` | 读取应用前后台切换、使用时长等使用情况元数据（特殊权限，需在系统设置中授予） |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` | 常驻“正在记录”前台服务，状态可见、可随时暂停 |
| `POST_NOTIFICATIONS` | 显示常驻通知（Android 13+ 运行时申请） |

### 可选插件（默认关闭，逐项显式授权）

> 下列插件默认关闭；开启并授予对应系统权限后按开关采集，未授权或关闭时采集端静默跳过、不写插件事件表。采集边界如下。

| 插件 | 状态 | 读取内容（脱敏后） | 风险 |
|---|---|---|---|
| 通知元数据 | 已接入 | 包名、频道、时间戳；**不读正文** | 中：通知元数据仍可能暴露使用节律 |
| 地理围栏 | 已接入 | 手动录入常去点的到达/离开；**不采连续轨迹** | 中低：位置相关 |
| Health Connect | 占位未接入 | 规划只读睡眠窗口、步数；受 Health Connect SDK 版本兼容限制，本版不采集，开关禁用 | 低：健康数据 |
| 日历 | 已接入 | 事件起止时间，做计划 vs 实际对照；**不读标题/地点/参与者** | 中：可能暴露日程节律 |
| 通话日志 | 已接入 | 方向、时长、日期；号码仅存 SHA-256 截断摘要，**不记号码原文/联系人** | **高风险**：通话行为敏感，设置页显著警示 |

> 无障碍 / OCR / 截图能力 **MVP 不实现**；未来若实现，必须默认关闭、本地脱敏并逐次征得用户确认。

## 隐私与删除

- 所有数据存于应用私有目录，数据库加密；不参与系统云备份与设备迁移拷贝。
- 设置页提供“暂停记录”和“一键删除全部数据”。
- **自动确认记忆**默认开启：开启时，本地模型成功生成且通过输出校验、与已有正式记忆/标签不重复的草案自动裁决；其中仅记忆要点写入正式记忆，状态标签与回顾文案只标记为已确认、不沉淀为长期记忆。开关可随时关闭，关闭后新产出回到人工确认队列。模板降级、超时或异常产出不会自动入库，仍进队列并在主界面弹窗提示一次。模型仍不回写数值、不输出诊断结论。已入库记忆可在记忆本/队列页撤销，并标注人工确认或自动确认来源。
- **手写片段**：队列页「记一笔」录入，可选心情与粗类别，提交即入正式记忆、不经草案队列，可在列表删除；应用不读取相册、通讯录或聊天内容。
- **自定义里程碑**：队列页可建立本人阶段节点，附可选自定义标签与说明，与规则徽章、模型状态标签分区呈现；按标题去重，可删除；随导出/导入与加密备份一并迁移。
- **本地明文 JSON 导出**默认关闭：开启后经系统文件选择器（SAF）由你选定本地文件，导出已确认记忆、状态标签、回顾文案、规则分值、徽章、手写片段与里程碑；原始使用事件（仅粗类别与时长）是否纳入可在导出前勾选。待确认/已丢弃草案、推理日志不导出。
- **本地导入**：经系统文件选择器（SAF）读取你手动选定的本地 JSON；导入前校验格式与 `schemaVersion`，记忆/标签/回顾文案/分值/徽章/片段/里程碑按指纹查重跳过、不覆盖已有正式记忆。可在三种冲突策略间切换（跳过重复 / 覆盖 / 全部追加）；最近一次导入结果（含失败原因与时间）会在设置区长期留痕。待确认/已丢弃草案、推理日志不导入。
- 导出文件为**明文**，落到应用私有目录之外后不再受数据库加密保护，请自行妥善保管；应用不联网上传、不写剪贴板。
- **加密备份**：队列页「加密备份」用你设置的口令经 PBKDF2-HMAC-SHA256 派生密钥、AES-GCM 加密可迁移数据（确认记忆、状态标签、分值、徽章、手写片段，原始事件可选）后写本地文件；换机或重装后选择该文件、输入同一口令即可解密并查重恢复。备份包不含库内 SQLCipher 口令与 Keystore 条目，新设备自行生成库密钥包装；**口令遗忘即不可恢复，无云端找回**。应用不联网、不写剪贴板。
- 详见 [`PRIVACY.md`](PRIVACY.md)。

## 构建（可复现）

- 工具链（阶段 0 实测）：JDK 17.0.21、Gradle 8.14.7（Wrapper）、Android SDK Platform 35、Build-Tools 35.0.0；compileSdk 35 / minSdk 26 / targetSdk 35。NDK 27.0.12077973、CMake 3.31.1。
- 首次构建前在 `local.properties` 配置 `sdk.dir=<本机 SDK 路径>`（本机为 `D:\\tools\\SDK`）；该文件不提交 git。
- 原生推理库（`libminepanel-llama.so`）需要本机一份 llama.cpp 源码目录，不进仓库：通过环境变量 `LLAMA_SRC_DIR`，或在 `local.properties` 中写 `llama.src.dir=<llama.cpp 源码路径>` 指定；未配置时 CMake 阶段报清晰错误。
- 清单红线检查：`pwsh -File tools/check_manifest.ps1`（源码清单与合并后清单均可传入）。
- Wrapper 默认指向国内镜像 `mirrors.cloud.tencent.com/gradle`；海外环境可在 `gradle/wrapper/gradle-wrapper.properties` 改回 `https://services.gradle.org/distributions/gradle-8.14.7-bin.zip`。
- 基线 GGUF 模型随包内置（`assets/models/bundled-model.gguf`，约 469 MiB）：首次启动在后台幂等拷贝到应用私有目录并做 SHA-256 基线校验，默认接入该内置副本，无需手动选择；也可在设置页另行选择本地 GGUF 替换。内置模型使 APK 体积相应增大约 491 MB。
- 运行单测：`./gradlew :app:testDebugUnitTest`（当前 217 个 JVM 用例，37 个测试文件）；真机 instrumented 测试：`./gradlew :app:connectedDebugAndroidTest`（队列 ViewModel 用例跑在已连接设备上、使用内存库不触碰真库；1 条破坏性本机往返测试 `@Ignore` 跳过，需手动移除注解后单跑）；构建 release：`./gradlew :app:assembleRelease`（R8 混淆 + 资源压缩；JNI 桥类与 native 方法名已在 `proguard-rules.pro` 保留）。

### 签名与仓库不含的内容

- **签名密钥不进仓库**：release 签名配置读取本地 `keystore.properties`（指向 `app/keystore/release.keystore`），二者均被 `.gitignore` 忽略。克隆本仓库后若没有该文件，release 构建自动回退 debug 签名，仅用于本机调试；**对外分发前必须生成你自己的 release 密钥**并配置到 `keystore.properties`，密钥库离线备份、丢失后无法给老用户发更新。
- **内置模型权重不进仓库**：`*.gguf` 被忽略，源码仓库不携带 468.6 MiB 的基线权重。克隆源码后若要复现内置包，从 v0.1.0 Release 下载 [`bundled-model.gguf`](https://github.com/libingyou527-sketch/mine-panel/releases/download/v0.1.0/bundled-model.gguf)（491,400,032 字节，SHA-256 `74A4DA8C9FDBCD15BD1F6D01D621410D31C6FC00986F5EB687824E7B93D7A9DB`；v0.2.0 权重未变更，沿用该附件），放到 `app/src/main/assets/models/bundled-model.gguf` 再构建；未放置时构建仍可成功，包内不含内置模型，推理回退模板兜底，也可在应用内自选本地 GGUF。权重归属与许可见 [`NOTICE.md`](NOTICE.md)「内置模型权重」。
- `local.properties`（SDK 路径、llama.cpp 源码路径）不提交；原生库需要本机一份 llama.cpp 源码目录，见上一节。
